## 主要项目 / 主なプロジェクト

### 🌐 [mtop-website](https://github.com/samuraiitumo/mtop-website) — M-TOP 企业官网 / M-TOP 企業サイト *(Private)*
Astro 静态前台 + Vue 3 管理后台 + FastAPI / SQLite API 的完整企业站，带后台一键发布、Docker / Nginx 部署手册。
Astro の静的フロントエンド + Vue 3 管理画面 + FastAPI / SQLite API で構成する企業サイト。管理画面からのワンクリック公開、Docker / Nginx のデプロイ手順書付き。
**Tech:** Astro · Vue 3 · FastAPI · SQLite · Tailwind CSS · Docker

### 📌 [links](https://github.com/samuraiitumo/links) — 本地链接管理桌面应用 / ローカルリンク管理デスクトップアプリ *(Private)*
Electron + Vue 3 跨平台桌面应用：文件夹、文件、应用、任务等快捷方式的动态分类管理与一键启动，数据存本地 SQLite，中 / 日 / 英三语。
Electron + Vue 3 のクロスプラットフォーム・デスクトップアプリ。フォルダ、ファイル、アプリ、タスクなどのショートカットを動的に分類管理し、ワンクリックで起動。データはローカルの SQLite に保存し、中・日・英の 3 言語に対応。
**Tech:** Electron 30 · Vue 3 · TypeScript · Vite · Element Plus · Pinia · SQLite

### 📄 [rick_tool](https://github.com/samuraiitumo/rick_tool) — PDF 合同表格识别工具 / PDF 契約書の表認識ツール *(Private)*
Windows 上批量处理 PDF 合同：转图、OpenCV 检测表格、RapidTable 识别，再写入 Excel 宏模板导出。
Windows で PDF 契約書を一括処理：画像化し、OpenCV で表を検出、RapidTable で認識して、Excel マクロテンプレートに書き出します。
**Tech:** Python · RapidTable · OpenCV · pdfminer.six · pandas · xlwings

### 🔍 [tableScanner](https://github.com/samuraiitumo/tableScanner) — 截图表格识别工具 / スクリーンショット表認識ツール
PyQt6 桌面小工具：框选屏幕区域，RapidOCR + RapidTable 把图片表格还原为结构化表格，托盘运行。
PyQt6 のデスクトップツール。画面の範囲を選択すると、RapidOCR + RapidTable で画像内の表を構造化データに復元します。システムトレイで動作。
**Tech:** Python · PyQt6 · RapidOCR · RapidTable · NumPy
